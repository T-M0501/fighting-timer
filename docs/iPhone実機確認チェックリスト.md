# iPhone / Android 実機で確認してほしいこと

1. **音量**: 設定 → 試聴 の4つのボタンを、音量100%・本体音量最大で鳴らす。いつものタイマーアプリと聞き比べる。※「必ず大きくなる」とは保証できません。
2. **サイレントスイッチ**: 消音スイッチ(側面)をオン/オフにして電子音が鳴るか確認。鳴らない場合は教えてください。
3. **音声ガイド**: 「音声ガイド」ボタンで日本語が読み上げられるか。
4. **実行**: 短いメニュー(運動5秒・休憩3秒・2種目)を作り、最後まで実行。音・色・文字の大きさ・ボタンの押しやすさ。
5. **一時停止→再開**: 3秒カウント後に続きから再開するか。
6. **画面ロック/別アプリ**: 実行中にホームボタン等で離れて10秒後に戻り、残り時間が実際の経過分進んでいるか（離れている間の音は鳴らないのが仕様上の限界です）。
7. **ドラッグ並び替え**: メニュー編集で「⠿」を指でドラッグ。
8. **オフライン**: ホーム画面から一度開いた後、機内モードで起動できるか。
9. **バックアップ**: 設定 → バックアップを保存 →「ファイルに保存」。その後「バックアップから復元」で選べるか。
10. **縦・横**: 横向きでタイマー画面が見切れないか。
