# Fighting Timer 使い方・公開・更新手順（初心者向け）

## A. iPhoneに追加する
1. iPhoneの **Safari** で、教えられたURLを開く（Chromeではなく必ずSafari）。
2. 下の共有ボタン（□に↑）をタップ →「**ホーム画面に追加**」→「追加」。
3. ホーム画面のアイコンから起動する。最初の1回だけ通信が必要。以降はオフラインでも使えます。

Android: Chromeで開き、メニュー(︙)→「ホーム画面に追加」（または「アプリをインストール」）。

## B. 基本の使い方
- ホームで「メニューを新規作成」→ 名前・時間・種目を入力 →「保存」。
- メニュー一覧の「開始」でタイマー画面へ。もう一度「開始」で始まります。
- 大切なデータ（メニュー・履歴）は端末の中だけに保存されます。**機種変更や削除に備えて、ときどき 設定 →「バックアップを保存」** を使ってください。

## C. 無料で公開する（GitHub Pages）※初回のみ
1. https://github.com でアカウントを作る（無料）。
2. 新しいリポジトリ（Public）を作る。名前例：`fighting-timer`。
3. Claude Codeに「GitHub Pagesに公開して」と伝える（ログインの案内を出します）。
4. 公開URL（例：`https://ユーザー名.github.io/fighting-timer/`）を家族・友人に共有。

## D. アプリを更新したとき
Claude Codeに「更新を公開して」と伝えるだけです（内部で `npm run stamp` を実行して版番号を更新し、公開します）。利用者の端末は、トレーニング中・メニュー編集中でないときに自動で新しい版に切り替わり、データは消えません。

## E. 開発者向け（Claude Code用）
```
npm test         # 自動テスト
npm run serve    # http://localhost:8080 で確認
npm run stamp    # 公開前に版番号を更新（sw.js と js/version.js）
npm run icons    # 仮アイコンの再生成（本アイコンはicons/内のPNGを差し替え）
```
